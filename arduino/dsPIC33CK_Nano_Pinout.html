Left header is J2, right header is J3, both numbered from the USB-C end (pin 1 = 5V / 3V3). The rows are 0.9″ (22.86 mm) apart, so the board straddles a standard breadboard. The AN channel and the A name are different numbers on this chip — use the A name in sketches.

3.3 V only. The I/O pins are not 5 V tolerant. The 5V pin is USB power after the diode (about 4.6 V) — an output for modules, never a signal level.

  • tone() borrows timer SCCP4, which is the PWM of D8. Don't use analogWrite(8, …) while a tone plays.
  • RB5/RB6 (D10/D11) are the ICSP lines. They are free I/O when no debugger is connected, but anything wired there can disturb programming.
  • RB10–RB15, RD1 are the motor-control PWM pins of the chip (PWM1H..PWM4H); in Arduino they are ordinary digital I/O.
  • PORTA (RA0–RA4) has no PPS, so no remappable peripheral can use it; it is the best place for analog inputs.

Getting started

  1. Install XC-DSC v4.00+ (compiler) and MPLAB X (for uploading with a PICkit/SNAP).
  2. In File > Preferences > Additional boards manager URLs add https://raw.githubusercontent.com/microchipthailand/dspic33ck-nano/main/package_dspicnano_index.json, then Tools > Board > Boards Manager → search dsPIC33CK Nano → Install. The device packs are installed automatically.
    Alternative for core development: copy arduino/hardware into your sketchbook so you get <sketchbook>/hardware/dspicnano/dspic33ck/boards.txt (do not use both at once).
  3. Tools > Board → dsPIC33CK Nano (dsPIC33CK256MC005). Tools > Debugger → the programmer you have on J4.
  4. Power the board from USB-C, plug the PICkit into J4 (pin 1 = MCLR, square pad), and upload File > Examples > dsPIC33CK_Nano > Lab01_Blink.

Optional: upload over the J5 serial port (no PICkit)

  1. Once, with the PICkit: Tools > Burn Bootloader.
  2. Connect a 3.3 V USB-serial adapter to J5 (adapter RX → J5-2, adapter TX → J5-3, GND → J5-4), pick its COM port.
  3. Tools > Bootloader → Serial over J5 (UART 115200), then Upload as usual.
  4. If the sketch running on the board doesn't use Serial, the upload can't reset it. Hold USER, press and release RESET, keep holding USER for about a second (the LED stays on), then upload.

Uploading with the PICkit erases the bootloader. Burn it again before going back to serial uploads.
